# OppoDesk — прототип «DeX» для OPPO Find X9 Ultra

Рабочий стол на внешнем мониторе: сетка приложений с поиском, панель задач
(Пуск, Назад, недавние приложения, часы), курсор и тачпад на экране телефона.

## Как собрать APK

**Через GitHub (без компьютера)**
1. Создайте репозиторий на github.com и загрузите в него содержимое этого архива.
2. Вкладка Actions → Build APK → Run workflow.
3. После сборки скачайте артефакт `OppoDesk-apk`, внутри `app-debug.apk`.

**Через Android Studio**
Откройте папку проекта, дождитесь синхронизации, Build → Build APK(s).

## Первый запуск
1. Установите APK и откройте OppoDesk.
2. Нажмите «Включить службу OppoDesk» и включите её в специальных возможностях.
   Служба нужна для курсора, панели задач и нажатий на мониторе.
3. Подключите монитор кабелем — рабочий стол откроется сам.
4. Экран телефона работает как тачпад.

## Окна вместо полноэкранного режима
Приложение просит систему открывать программы окнами. Сработает это, только если
в прошивке включены свободные окна. Попробуйте:
- Параметры разработчика → «Разрешить окна произвольной формы» и
  «Изменение размера в многооконном режиме», затем перезагрузка;
- либо через ADB:
  ```
  adb shell settings put global enable_freeform_support 1
  adb shell settings put global force_resizable_activities 1
  adb reboot
  ```
Если ColorOS эти настройки игнорирует, приложения будут открываться на весь
монитор, а панель задач останется поверх нижнего края.

## Состояние
Код компилируется, но на реальном телефоне не проверялся. Возможны правки под
поведение ColorOS 16.
